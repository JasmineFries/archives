## 问题 A: 陈氏素数个数

### 原题

### 题目内容
如果一个数本身是素数，他的相反数（倒过来的数）也是素数，则把这个素数称为陈氏素数。如13是素数，相反数31也是素数。如149是素数，941也是素数。则13/149都是陈氏素数。
编程求10～n(n为大于10的正整数)中有多少个陈氏素数。
https://www.bilibili.com/video/BV1KSeuz6EvK/?vd_source=398d1f1b78a749026d665c575cad4731

### 输入要求
格式
n(2≤n≤50000)。
样例
100

### 输出要求
格式
陈氏素数的
个数。
样例
9

### 分类标签
循环

### 答案

核心：判断 `x` 是素数，并且 `reverse(x)` 也是素数。

```cpp
#include <bits/stdc++.h>
using namespace std;

bool isPrime(int x){
    if(x < 2) return false;
    for(int i = 2; i * i <= x; i++)
        if(x % i == 0) return false;
    return true;
}

int revNum(int x){
    int r = 0;
    while(x){
        r = r * 10 + x % 10;
        x /= 10;
    }
    return r;
}

int main(){
    int n;
    cin >> n;
    int ans = 0;
    for(int i = 10; i <= n; i++)
        if(isPrime(i) && isPrime(revNum(i))) ans++;
    cout << ans << endl;
    return 0;
}
```

如果一个数从左边读和从右边读都是同一个数，就称为回文数。例如101就是一个回文数，求出所有的既是回文数又是素数的三位数。

### 输入要求
一个m,n（100<m<n<1000）
格式
m n
样例

### 输出要求
m到n之间的所有回文素数。
格式
所有的既是回文数又是素数的三位数。
样例
101 131 151 181 191

### 分类标签
函数

### 答案

核心：区间内同时满足“回文”和“素数”。

```cpp
#include <bits/stdc++.h>
using namespace std;

bool isPrime(int x){
    if(x < 2) return false;
    for(int i = 2; i * i <= x; i++)
        if(x % i == 0) return false;
    return true;
}

bool isPal(int x){
    int old = x, r = 0;
    while(x){
        r = r * 10 + x % 10;
        x /= 10;
    }
    return old == r;
}

int main(){
    int m, n;
    cin >> m >> n;
    bool first = true;
    for(int i = m; i <= n; i++){
        if(isPrime(i) && isPal(i)){
            if(!first) cout << ' ';
            cout << i;
            first = false;
        }
    }
    cout << endl;
    return 0;
}
```

```cpp
#include <bits/stdc++.h>
using namespace std;

bool isPrime(int x){
    if(x < 2) return false;
    for(int i = 2; i * i <= x; i++)
        if(x % i == 0) return false;
```

```cpp
}

int diffSum(int x){
    vector<int> d;
    while(x){
        d.push_back(x % 10);
        x /= 10;
```

## 问题 G: 括弧匹配检验

### 原题

### 题目内容
假设表达式中允许包含两种括号：圆括号和方括号，其嵌套的顺序随意，如（［ ］（））或［（［ ］［ ］）］等为正确的匹配，［（ ］）或（［ ］（ ）或 ( ( ) ) ）均为错误的匹配。
现在的问题是，要求检验一个给定表达式中的括弧是否正确匹配？

### 输入要求
一个只包含圆括号和方括号的字符串，判断字符串中的括号是否匹配，匹配就输出 “OK” ，不匹配就输出“Wrong”。输入一个字符串：［（［］［］）］，输出：OK。
格式
仅一行字符（字符个数小于255）。
样例
[(])

### 输出要求
格式
匹配就输出 “OK” ，不匹配就输出“Wrong”。
样例
Wrong
数据范围与提示
视频讲解：
https://www.bilibili.com/video/BV1dXQVYvE8m/?vd_source=398d1f1b78a749026d665c575cad4731

### 分类标签
数据结构-栈

### 答案

核心：左括号入栈，右括号看栈顶是否匹配。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
    string s;
    cin >> s;
    stack<char> st;

    for(char c : s){
        if(c == '(' || c == '[') st.push(c);
        else{
            if(st.empty()){
                cout << "Wrong\n";
                return 0;
            }
            char t = st.top();
            st.pop();
            if((c == ')' && t != '(') || (c == ']' && t != '[')){
                cout << "Wrong\n";
                return 0;
            }
        }
    }

    cout << (st.empty() ? "OK" : "Wrong") << endl;
    return 0;
}
```

## 问题 L: 求二叉树的叶子结点个数

样例

### 输出要求
格式
有两行：
第一行是二叉树的中序遍历序列；

样例:

数据范围与提示

### 分类标签

### 答案

核心：先序建树，`#` 表示空；中序输出；左右孩子都空就是叶子。

```cpp
#include <bits/stdc++.h>
using namespace std;

string s;
int pos = 0, leaf = 0;

struct Node{
    char val;
    Node *l, *r;
    Node(char c): val(c), l(nullptr), r(nullptr) {}
};

Node* build(){
    if(pos >= (int)s.size()) return nullptr;
    char c = s[pos++];
    if(c == '#') return nullptr;
    Node* root = new Node(c);
    root->l = build();
    root->r = build();
    return root;
}

void inorder(Node* root){
    if(!root) return;
    inorder(root->l);
    cout << root->val;
    inorder(root->r);
}

void countLeaf(Node* root){
    if(!root) return;
    if(!root->l && !root->r) leaf++;
    countLeaf(root->l);
    countLeaf(root->r);
}

int main(){
    cin >> s;
    Node* root = build();
    inorder(root);
    cout << endl;
    countLeaf(root);
    cout << leaf << endl;
    return 0;
}
```

样例
3 6

### 分类标签
数据结构-最小生成树
acwing

### 答案

核心：选最少边连通所有点就是生成树；最大边尽量小，用 Kruskal，输出边数和最大边。

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Edge{
    int u, v, w;
};

int fa[305];

int find(int x){
    if(fa[x] == x) return x;
    return fa[x] = find(fa[x]);
}

int main(){
    int n, m;
    cin >> n >> m;
    vector<Edge> e(m);
    for(auto &x : e) cin >> x.u >> x.v >> x.w;

    sort(e.begin(), e.end(), [](Edge a, Edge b){
        return a.w < b.w;
    });

    for(int i = 1; i <= n; i++) fa[i] = i;

    int cnt = 0, mx = 0;
    for(auto x : e){
        int fu = find(x.u), fv = find(x.v);
        if(fu != fv){
            fa[fu] = fv;
            cnt++;
            mx = max(mx, x.w);
            if(cnt == n - 1) break;
        }
    }

    cout << cnt << ' ' << mx << endl;
    return 0;
}
```
